# HG-KIND-001

## Meaning

The document uses an unknown schema, kind, signal, action, or packaging value.

## Cause

A typo, a competing vocabulary, or a document that is not a hostguard
interview or policy.

## Resolution

Use only the kinds declared in `schemas/hostguard-policy.schema.json`. Do not
invent a parallel language; this pack sits on `wellmanifest/dsl`.
